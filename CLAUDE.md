# FM1975 – Arbeitsanleitung für Claude

Browser-Fußballmanager „1975 – A Football Manager“: Start 1975, Verein über Jahrzehnte mit sich ändernden Regeln führen.
React 18 + TypeScript, gebaut mit esbuild. Kein Backend – alles läuft im Browser (Spielstände in localStorage, eigene Wappen/Trikots in IndexedDB).

## Befehle
- `npm run check` – Typprüfung, muss **0 Fehler** ergeben.
- `npm run build` – Build nach `dist/`. `npm run dev` – lokaler Server auf http://localhost:5173.
- `node scripts/sim.mjs <n>` – n Saisons ohne UI (Balance-Bericht, `FIN=1` mit Finanzen); `node scripts/sim.mjs --world 50` – nur Europa.
- `node scripts/matchbench.mjs [n]` – Balance der Match-Engine je Epoche; `node scripts/tickerdemo.mjs [jahr] [seed]` – Textmodus auf der Konsole; `node tests/match-ui.mjs` – Oberflächentest Textmodus.
- `npm run test:ui` – Rauchtest (Playwright): startet ein Spiel, öffnet jede Seite, lässt Zeit laufen, meldet JS-Fehler. Screenshots in `test-output/`. Ablauf „Neues Spiel“ für Tests: `tests/newgame-flow.mjs`; Screenshots des Assistenten: `node tests/newgame-shots.mjs`.
- `npm run test:dataset` – Datensatz-Test ohne UI; `npm run test:editor` – Oberflächentest des Datensatz-Editors (Screenshots in `test-output/editor/`); `npm run test:business` – Stadionbau/Kredite/Namensrechte/Investor/Überschuldung ohne UI; `npm run test:contracts`, `npm run test:transfers`, `npm run test:youth`, `npm run test:stadium`, `npm run test:ai` – Verträge, Transferverhandlungen bzw. Jugendakademie bzw. Stadion-Blöcke bzw. Manager-KI ohne UI (`node tests/stadium-shots.mjs` = Screenshots der Stadionseite). `npm run test:winterbreak` – Winterpause je Epoche, Spielpläne aller Ligagrößen vor dem 30.6., keine Kollisionen Liga/Pokal/Europapokal/Halle. `npm run test:winter` – Hallenfußball (Saison 1990/91 komplett, Ende nach 2004) + Trainingslager (Freischaltung je Epoche, Unterkünfte, Schwerpunkte, Sponsor-Pflicht, Migration) ohne UI; Screenshots `node tests/winter-shots.mjs` (mit `SAVE=…` aus `DUMP=… UNTIL=1990-12-19 node scripts/sim.mjs 15`), Screenshots Trainingslager `node tests/camp-shots.mjs [ordner] [präfix]` (mit `SAVE=…`), Sim-Bericht `WINTER=1 node scripts/sim.mjs 30`.
