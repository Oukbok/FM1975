# FM1975 – Arbeitsanleitung für Claude

Browser-Fußballmanager „1975 – A Football Manager“: Start 1975, Verein über Jahrzehnte mit sich ändernden Regeln führen.
React 18 + TypeScript, gebaut mit esbuild. Kein Backend – alles läuft im Browser (Spielstände in localStorage, eigene Wappen/Trikots in IndexedDB).

## Befehle
- `npm run check` – Typprüfung, muss **0 Fehler** ergeben.
- `npm run build` – Build nach `dist/`. `npm run dev` – lokaler Server auf http://localhost:5173.
- `node scripts/sim.mjs <n>` – n Saisons ohne UI (Balance-Bericht, `FIN=1` mit Finanzen); `node scripts/sim.mjs --world 50` – nur Europa.
- `node scripts/matchbench.mjs [n]` – Balance der Match-Engine je Epoche; `node scripts/tickerdemo.mjs [jahr] [seed]` – Textmodus auf der Konsole; `node tests/match-ui.mjs` – Oberflächentest Textmodus.
- `npm run test:ui` – Rauchtest (Playwright): startet ein Spiel, öffnet jede Seite, lässt Zeit laufen, meldet JS-Fehler. Screenshots in `test-output/`. Ablauf „Neues Spiel“ für Tests: `tests/newgame-flow.mjs`; Screenshots des Assistenten: `node tests/newgame-shots.mjs`.
- `npm run test:dataset` – Datensatz-Test ohne UI; `npm run test:editor` – Oberflächentest des Datensatz-Editors (Screenshots in `test-output/editor/`); `npm run test:business` – Stadionbau/Kredite/Namensrechte/Investor/Überschuldung ohne UI; `npm run test:contracts`, `npm run test:transfers`, `npm run test:youth`, `npm run test:stadium`, `npm run test:ai` – Verträge, Transferverhandlungen bzw. Jugendakademie bzw. Stadion-Blöcke bzw. Manager-KI ohne UI (`node tests/stadium-shots.mjs` = Screenshots der Stadionseite). `npm run test:winterbreak` – Winterpause je Epoche, Spielpläne aller Ligagrößen vor dem 30.6., keine Kollisionen Liga/Pokal/Europapokal/Halle. `npm run test:winter` – Hallenfußball (Saison 1990/91 komplett, Ende nach 2004) + Trainingslager (Freischaltung je Epoche) ohne UI; Screenshots `node tests/winter-shots.mjs` (mit `SAVE=…` aus `DUMP=… UNTIL=1990-12-19 node scripts/sim.mjs 15`), Sim-Bericht `WINTER=1 node scripts/sim.mjs 30`. Sim-Bericht der Ablösen: `TRANSFERS=1 node scripts/sim.mjs 40`; Kaderbewegungen/Trainerwechsel der KI: `AI=1 node scripts/sim.mjs 30`. `npm run test:grounds` – Stadionumfeld ohne UI; Screenshots Vereinsgelände `node tests/grounds-shots.mjs [ordner] [kürzel]` mit `SAVE=…`. Akademie-Bilanz (Eigengewächse, Stars je Jahrzehnt, viel vs. wenig Investition): `YOUTH=1 node scripts/sim.mjs 50`; Screenshots Akademie/Jugend: `node tests/youth-shots.mjs` (`SAVE=…` für späte Epochen). `npm run test:finance` – Finanzniveau je Epoche ohne UI. `npm run test:briefing` – Saison-Briefing ohne UI (1975/76, 1995/96, 2002/03, Archiv, Saisonwechsel, Laden); Screenshots Popup + Archiv `node tests/briefing-shots.mjs` (mit `SAVE=…` aus `DUMP=… node scripts/sim.mjs 21` für spätere Saisons). Oberflächentests schließen das Briefing in `tests/newgame-flow.mjs` (`keepBriefing: true` lässt es offen). Breite der Spitze (Spieler ≥85/≥80 in Liga 1 nach Herkunft, je Jahrzehnt): `TOP=1 BAL=1 node scripts/sim.mjs 50`.
- Live: https://fm1975.pas-franke.workers.dev
- Hosting: Cloudflare Workers (statische Assets, `wrangler.jsonc`) baut jeden Push auf `main` automatisch (Build `npm run build`, Ausgabe `dist`).

## Feste Vorgaben von Pascal
- **Keine Emojis** in der UI – nur `<Icon>` (`src/components/iconPaths.ts`; neues Icon dort ergänzen).
- Genau **eine** Akzentfarbe: Bernstein `#F2A541` (Thema „Abendhimmel“ wie der Startbildschirm; kein Türkis mehr). Flächen in neutralen, leicht kühlen Schiefertönen – **kein Sepia/Braun-Schleier** (keine warmen Pflaumen-/Brauntöne für Hintergründe, Boxen, Rahmen, Grautexte; kein Bernstein-Schein auf Boxen; Hintergrundfotos entsättigt und kühl abgedunkelt, `00-base.css` `.app-shell::before`). Farben nur über die Tokens in `00-base.css`; Schriften: Oswald (`--font-display`, Titel/Menüs/Knöpfe, Großbuchstaben) + Barlow (`--font-ui`), Regeln in `25-theme.css`. Sprache Deutsch, informelles „du“.
- Währung DM bis 2001, EUR ab 2002 (`engine/economy.ts`). Datum **immer UTC**.
- Geld: Kontostand/Buchungen **nominal**; Preisschilder (Gehalt, Marktwert, Transferbudget, Prämien-/Vertragswerte) in **1975-Basis**, Anzeige mit `fmtPrice`, Buchung × `economyScale`. Finanzen 2.0 (Marke, TV, Vermarktung, KI-Haushalt, FFP) in `engine/clubEconomy.ts` + `game/seasonFinance.ts`. Finanzniveau nach Recherche: Erstligist 1975 ≈ 4,5 Mio. DM Umsatz (Spanne ≈ 2,5–9 Mio.), Stammspieler ≈ 75 Tsd., Star ≈ 250 Tsd. DM/Jahr; neue Preise/Kosten auf dieses Niveau setzen (Formeln: `docs/specs/FINANZEN_SPEC.md`).
- Zentrale (Dashboard): Footer unten lassen, Boxenhöhen nicht ändern, Boxen nur verschieben, ohne Scrollen.
- Neue Seiten: in `MENU_STRUCTURE` eintragen (erster Unterpunkt = Kategorie selbst), Kopf über `PageHead`, gerendert in `<main className="app-main">` unter `CalendarStrip`.
- Alle Vereine werden simuliert. Änderungen minimal und nicht-destruktiv; Spielstand-Kompatibilität beachten (`SAVE_VERSION` in `engine/save.ts`).
- **Wiki-Pflicht:** neue/geänderte Mechanik → passenden Artikel in `src/data/wiki.ts` mitpflegen (einzige Wiki-Quelle).

## Optik (erwachsen, ruhig – gilt für jede neue Seite)
- Flächen neutral, Rahmen dezent (`--border`/`--border-soft`), Radien klein (4–8 px); keine Verläufe aus Vereinsfarben – Vereinsfarbe höchstens als 3-px-Linie (`--club`, siehe `.pp-header`/`.cmx-head`).
- Text-Hierarchie über Tokens: `--text` Werte/Namen, `--text-2` Beschriftungen, `--text-3` Nebeninfo/Spaltenköpfe, `--text-4` gedimmt. Abschnittstitel klein, Großbuchstaben, `--text-3` (nicht Bernstein).
- Werte (Attribute, Stärke, Eignung) **monochrom**: `vColor`/`vBar` aus `ui/format.ts` (Skala `--q-1…4`). Keine Ampel-Balken. Zustände (Frische, Fitness, Moral, Vertrauen): `condColor`/`condBar` – neutral, erst bei niedrigen Werten Gelb/Rot.
- Bernstein (`--accent`) nur für Auswahl, aktiven Reiter, eigenen Verein, Hervorhebung (z. B. Schlüsselattribute) und Hauptknopf – nicht für Kennzahlen, Überschriften, Icons oder Listenwerte. Grün/Rot (`--pos`/`--neg`, gedämpft) nur für echte Signale (Saldo, Verletzung, Vertragsende, Trend, Tabellenzonen).
- Zahlen tabellarisch (global `tabular-nums`); große Kennzahlen in Oswald (`--font-display`), Gewicht 500–600, weiß. Wenige Icons: Box-Kopf-Icon grau, keine Icons vor Listenzeilen/Balken.
- Pillen/Badges sparsam, eckig (4 px), neutral; Positionskürzel als umrandetes Etikett (`.pos-badge`). Übergreifende Optik-Regeln stehen in `styles/29-look.css` (zuletzt geladen); Screenshots Vorher/Nachher: `node tests/look-shots.mjs [ordner]`.
