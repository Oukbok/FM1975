# FM1975 – Arbeitsanleitung für Claude

Browser-Fußballmanager „1975 – A Football Manager“: Start 1975, Verein über Jahrzehnte mit sich ändernden Regeln führen.
React 18 + TypeScript, gebaut mit esbuild. Kein Backend – alles läuft im Browser (Spielstände über einen Speicherort `SaveBackend` aus `engine/saveStore.ts`: Browser = IndexedDB `fm1975-saves`, Desktop-Fassung = Dateien im Benutzerordner, siehe „Desktop-Fassung“ – Umzug alter localStorage-Stände beim Start in `initSaveStore`, Tests spielen Stände weiter per localStorage ein; Rückfall localStorage; `saveGame`/`loadGame` sind async; Test `npm run test:saves`; Einstellungen in localStorage, eigene Wappen/Trikots in IndexedDB).

## Wo liegt was (nur die betroffene Datei lesen, nicht breit suchen)
- `src/App.tsx` – Wurzel: Hauptmenü ↔ Spiel; Spiel-Shell, Spielaufbau (`game/newGame.ts`) und Laden-Nachrüstungen (`game/loadMigrations.ts` `prepareLoadedGame` – Datensatz + alle `migrate*` in fester Reihenfolge, auch von `tests/season-test.ts` genutzt) werden nachgeladen. Build mit Code-Splitting (`scripts/build.mjs`: ESM, `dist/chunks/`, `<script type="module">`; läuft unter http(s)/Cloudflare und `app://` in Electron, nicht unter `file://`). Ladezeit messen: `node tests/startup-bench.mjs [läufe]` (`THROTTLE=4`, `WAIT=2500`).
- **Modul-Zustand & IDs** (neues Spiel = wie nach Neuladen): `game/resetModuleState.ts` `resetModuleState()` am Anfang von `createNewGame` und `prepareLoadedGame` setzt allen Modul-Zustand zurück (Transferdatum, Trainerteams/Weltklasse-Bremse/Epochen-Ausgleich, Jugend-Salz/-Verschiebung, Talent-Angebot, Generator-Startwerte, Spieljahr der Positionen/Formationen, Verletzungs-Haken, Euphorie, Heimatland/Währung/Anzeigejahr, Meldelisten, Auszeichnungs-/Werbe-/Stab-Wirkung, Transferprotokoll-Empfänger, vorbereitete Spiele, Zwischenspeicher); jedes Modul hat dafür eine kleine `reset…`/`clear…`-Funktion – **neuer Modul-Zustand (top-level `let`, Cache, Setter) → dort eintragen**. Nicht zurückgesetzt: Datensatz (`applyDataset`, Wappen-Datum) und App-Einstellungen. Stammdaten nie direkt in den Spielstand geben (`allEuroClubs()` liefert Kopien).
