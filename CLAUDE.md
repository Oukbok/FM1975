# FM1975 – Arbeitsanleitung für Claude

Browser-Fußballmanager „1975 – A Football Manager“: Start 1975, Verein über Jahrzehnte mit sich ändernden Regeln führen.
React 18 + TypeScript, gebaut mit esbuild. Kein Backend – alles läuft im Browser (Spielstände in localStorage, eigene Wappen/Trikots in IndexedDB).

## Befehle
- `npm run check` – Typprüfung, muss **0 Fehler** ergeben.
- `npm run build` – Build nach `dist/`. `npm run dev` – lokaler Server auf http://localhost:5173.
- `node scripts/sim.mjs <n>` – n Saisons ohne UI (Balance-Bericht, `FIN=1` mit Finanzen); `node scripts/sim.mjs --world 50` – nur Europa.
- `node scripts/matchbench.mjs [n]` – Balance der Match-Engine je Epoche inkl. Ist/Soll-Tabelle (`MODE=era`, `MIX=1` Chancenmix; `MODE=attrs` Attribut 60 vs. 85, `MODE=tactics` Taktik-Wirkung, `YEAR=…`, Code `tests/enginebench.ts`); `node scripts/run-ts.mjs tests/matchspeed.ts [n]` – Rechenzeit je Spiel; Screenshots Taktik/Spielbericht `node tests/engine-shots.mjs`; `node scripts/tickerdemo.mjs [jahr] [seed]` – Textmodus auf der Konsole; `node tests/match-ui.mjs` – Oberflächentest Textmodus (Wechsel-Bildschirm, Halbzeit-Stopp, Aufwärmen, Co-Trainer); `npm run test:sideline` – Seitenlinie ohne UI (Aufwärmen, Co-Trainer, wartender Verletzter, Umstellung, Gespräche, Wechsel-Entwurf); Screenshots `node tests/textmode-shots.mjs [ordner] [präfix]` (`SAVE=…`).

Jugendakademie bzw. Stadion-Blöcke bzw. - `npm run test:legends` – Ausnahmetalente (100 Einträge, verfremdete Namen, Spawn-Jahr/Verein/Gewichtung, Option aus, keine Nachrichten, verdeckte Werte nie als Zahl im UI); Sim-Bericht `LEGENDS=1 node scripts/sim.mjs 50`.
- `npm run test:euro2` – Europapokal 2.0 ohne UI (je Epoche 1975/85/92/2000/05/15/22/25: Format, Hin-/Rückspiel, Auswärtstore, Gruppen/Ligaphase, Wechsel der Gruppendritten, Termine, Statistik aller Spiele, Archiv; Landespokal-Wiederholungsspiele; alter Spielstand im alten Modus).
